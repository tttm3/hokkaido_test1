# 北海道堆肥検索サイト

宮崎県の堆肥検索サイトをベースに、北海道のエリアと市町村データを使用した堆肥検索サイトです。

## 機能

- 散布方法の選択（自分で散布 / 散布までしてほしい / 決めていない）
- 堆肥の生産地で絞り込み（エリア・市町村選択）
- 畜種で絞り込み（牛ふん / 豚ふん / 鶏ふん / その他）
- 荷姿で絞り込み（バラ / フレコン / トラック・ダンプ / その他）
- 散布対象場所で絞り込み（エリア・市町村選択）
- 検索機能

## 使用方法

1. `index.html`をブラウザで開く
2. 各セクションで条件を選択
3. 「この条件で検索」ボタンをクリック

## ファイル構成

- `index.html` - メインのHTMLファイル
- `styles.css` - スタイルシート
- `script.js` - JavaScript機能
- `data.js` - 北海道エリアと市町村データ

## 地図画像の使用

実際の市町村地図画像（`市町村.png`）を使用する場合：

1. `市町村.png`をプロジェクトフォルダに配置
2. `script.js`の`hasMapImage`を`true`に変更

## 北海道エリア

以下の9つのエリアに分類されています：

1. 稚内・宗谷エリア
2. 網走・北見・紋別エリア
3. 釧路・根室エリア
4. 十勝エリア
5. 胆振・日高エリア
6. 函館方面エリア
7. 札幌・小樽エリア
8. 空知エリア
9. 旭川・留萌エリア
